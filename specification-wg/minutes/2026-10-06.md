# Specification WG (SPEC-WG) — 2026-10-06

## Agenda

1. New working-group features on veranafoundation.org (meeting editing, automatic transcripts and minutes)
2. Private groups, GitHub backup repositories and MCP access
3. Onboarding of a new contributor ("Lin") and playground use cases
4. Prerequisites before giving external people deployment access

## Discussion

**Working-group features on veranafoundation.org.** Fabrice Rochette demonstrated changes he made to the foundation website. Individual meetings in a series can now be moved or cancelled without affecting the rest of the series, which was the change Ariel Gentile had requested. Automatic transcription and AI-generated minutes have been added: roughly ten minutes after a session ends, group leads receive an email pointing to a "past session minutes" page containing an editable Markdown draft, which leads can approve, change or reject. For public groups, approved minutes are published to GitHub; publishing the raw transcript is optional. An executive summary is shown on the group page, with the full detail available behind it. The feature can be disabled per group.

Fabrice noted a current limitation: Google Meet transcription cannot detect the meeting language automatically, and because the account used is configured in English, Spanish meetings are transcribed in English by default. The workaround is to stop the transcript manually and restart it in Spanish. He also noted that Spanish transcription is only alpha-level support and may not work well. Ariel said the mechanism should simply be tried out.

**Private groups and MCP.** Groups can now be created as private: the group is visible, but sessions and minutes are restricted to members, and join requests must be approved by the leads. Fabrice gave the internal meeting with the France team as a candidate use case, to keep a record of what was discussed. He also described an MCP endpoint with a per-user token, allowing an AI assistant to search minutes and transcripts, and his intention to combine it with the MCP of the CRM in use so that actions mentioned in a meeting can be reflected in the CRM. He added that token-based configuration works with Claude Code but not with Claude, so he implemented an OAuth redirect flow (sign-in to the Verana Foundation, then return with a token); this was not yet merged. Content is also backed up to two GitHub repositories, one public for public groups and one private ("Private Working Groups") for private groups.

**Onboarding "Lin" and playground use cases.** Fabrice said he could not attend the scheduled meeting with Lin because of a conflicting appointment with Julian Bonilla of an integrator named Grow Data, and asked whether Ariel could take it. Ariel replied he was not in a position to, as he had no prepared material and already had a session with another contributor ("Martin"), whom he wanted to support properly.

Fabrice forwarded Ariel an example of an incoming request and argued that demand for short-lived playground demos and use cases is growing, that he currently builds them himself, and that someone else could take this over. He proposed Lin start by deploying services, reproducing existing use cases and then creating new ones (for example testing credentials with a wallet), which would also teach him how Verana works.

Ariel agreed with the direction but objected that an unknown person doing deployments requires the groundwork to be in place first: the separate cluster for the playground discussed previously, so that the indexer and current infrastructure are not affected, and a reasonably organised playground repository. Fabrice suggested devnet or a test cluster as a possible environment. Ariel also raised the practical difficulty of the time-zone gap, suggesting that in the meantime Lin ask questions on Discord. Fabrice proposed inviting him to the Implementation Working Group so he could listen in; Ariel had no objection but was unsure how much value it would add.

## Decisions

- The meeting with Lin will be postponed to the following week (next Monday was mentioned), as the material he is meant to investigate is not yet prepared.
- Lin will be asked to register on the Verana Foundation site and join the working group; inviting him to the Implementation Working Group as a listener was accepted without objection.
- Before giving Lin deployment access, the playground must run on a separate cluster and the playground repository must be organised.
