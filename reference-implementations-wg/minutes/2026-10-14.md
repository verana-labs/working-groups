# Reference Implementation WG — 2026-10-14

## Agenda

1. Test net migration to V4 and move to a new cluster
2. Deploy repo centralisation and the ECS deployment PR
3. Hologram app update and store release
4. Playground wallets and DIDComm v1/v2 status
5. Indexer issues, TRQP gaps and the 2.1 release
6. Frontend issues and front-end documentation PR
7. V5 roadmap, tokenomics, governance and upcoming business context
8. Communication about test net downtime

## Discussion

**Test net migration.** Ariel Gentile introduced the main topic: migrating the test net to V4 and moving it onto a dedicated cluster so it is no longer sharing resources with the playground and demo services. Andres Vallecilla reported that deployment of the blockchain had been started the previous day; after some problems it was fixed and the chain is now running. Services were being redeployed on the new cluster: dashboard, indexer and the "fer" service were already deployed, with more to follow. Andres questioned whether the graph needed to be deployed at this stage; Fabrice Rochette stated that everything must be deployed, including the graph and the search.

**Deploy repo and ECS PR.** Andres explained that the deploy repo now centralises blockchain deployment, with a full deployment path and a binary-refresh path, replacing a previously multi-step and complex process. Ariel presented a PR extending the ECS ecosystem/organisation issuer setup (previously devnet only) to the testnet, removing the older V3 transactions and fixing the schema mode issue Fabrice had raised. He noted new secrets (mnemonics per environment) would be needed and that he had left pre- and post-merge instructions in the PR body, some of which may no longer apply after the cluster move. Andres said he would review the environment structure for consistency and also address Maxime's comments on the configuration file, requiring a front-end update he described as not complicated. Ariel noted the wiped devnet had taken under an hour to redeploy with demo services.

**Hologram.** Ariel said the Hologram app is already updated for V4 and only awaits publication. Maxime Mansiet had tested on dev-net and would test the test net once migration completed, after which the update could be published. Known issues remain: dark-mode support for some widgets (issue opened by Fabrice) and a presentation-request QR code showing the invitation screen before the presentation request; Ariel was unsure whether the cause is in Hologram or in how VS Agent constructs the invitation. The plan is to publish now and release store updates more frequently.

**Playground wallets and DIDComm.** The basic use cases (Vesta, Verandia, BHI, crypto exchange) worked on devnet with Hologram, WWWallet, Inji and EUDI. Maxime reported the Swiss wallet introduced encryption in version 1.18 which Credo does not yet support; version 1.16 works on devnet and will be used on the playground, with the fork updated once Credo supports the encryption. Hologram still uses DIDComm v1 for stability while inter-service communication already uses v2; once remaining Credo fixes land, VS Agent, Hologram and the mediator can be upgraded.

**Indexer and TRQP.** Open indexer issues remain, including an open PR with unaddressed review comments. Andres said he had reviewed the specs and listed several small TRQP gaps that still need finishing, but is occupied with the migration. Pratik Kumar accepted taking over these issues. Ariel said release 2.1 could follow once they are done.

**Frontend and documentation.** Maxime reported many issues already closed; roughly three or four remain without PRs, and he considered issue 503 (onboarding service, join wizard and new screens) the top priority. He had opened a documentation PR for the front end including screenshots in light and dark mode, aimed at non-technical users onboarding their service. Fabrice said this was on his own roadmap, welcomed it, and would review and merge; he added the VS-Agent build section of the documentation is confusing and that a new working group starting Thursday would cover documentation and playground demo deployment.

**V5 and context.** Fabrice outlined what follows V4: schema attribute additions on the blockchain with impact on VS-Agent, the tokenomics update agreed with Philip (a pull request from Pratik is pending review), a new governance model, and Cosmos SDK upgrade / group module work already underway. Most effort would shift to applications, including the Colombia commercial chamber project, plus a planned SaaS offering (indicative price mentioned: $10 per month), a certification programme, and a Colombian company joining the foundation as an associate member.

**Downtime communication.** Fabrice stressed that people use the playground daily for demos, cited a cancelled meeting caused by uncertainty about testnet availability, and asked Andres to post progress and estimated restoration times in Discord roughly every three hours. Andres acknowledged this.

## Decisions

- Everything, including the graph and search services, is to be deployed on the new test net cluster.
- Hologram's V4 update will be published once Maxime confirms it works against the testnet, with fixes released in subsequent store updates.
- The Swiss wallet will be integrated at version 1.16 until Credo supports the 1.18 encryption.
- The open indexer/TRQP issues are reassigned to Pratik Kumar.
